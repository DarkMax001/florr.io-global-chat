# florr.io-global-chat

# Special Chat - Tampermonkey Script

A simple chat enhancement script for [florr.io](https://florr.io) that adds a way to globally interact with others without discord!

---

## Features

- Shows a system message when a user joins: `<user> has joined the conversation`
- Welcomes first-time users: `<user> is here for the first time, welcome them!`
- Customizable chat box appearance
- Works entirely client-side via Tampermonkey

---

## Installation

1. Install [Tampermonkey](https://www.tampermonkey.net/) for your browser.
2. Click **Add new script** in Tampermonkey.
3. Copy and paste the contents of `Special-Chat.user.js` into the editor.
4. Save and enable the script.
5. Open [florr.io](https://florr.io) and enjoy enhanced chat messages.
